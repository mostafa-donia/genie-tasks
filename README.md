## 🎯 مميزات المنصة الرئيسية

### 1. لا تشتيت للطفل (Zero Clutter):
- عرض **سؤال واحد فقط في الصفحة** ببطاقة كبيرة ومريحة للعين.
- لغة مصرية واضحة ومباشرة بدون حشو جانبي أو تعقيد.
- شريط ملاحة علوي يوضح رقم كل سؤال وحالته بالألوان:
  * 🟢 **أخضر**: تم الحل والتسليم بنجاح.
  * 🟡 **أصفر**: تم تخطي السؤال مؤقتاً (Skip) ويمكن العودة له بأي وقت.
  * ⚪ **رمادي**: سؤال لم يفتح بعد.
  * 🟣 **إطار بنفسجي مشع**: السؤال النشط حالياً.

### 2. التسليم التراكمي (سؤال بسؤال):
- الطالب مش محتاج يحل الواجب كله في جلسة واحدة!
- يقدر يحل سؤالين النهاردة ويتسلموا فوراً ويتحفظوا للمدرس، ويكمل الباقي على مدار الأسبوع.
- زر **تخطي مؤقت (Skip ⏭️)** يتيح للطفل عدم التعطل أمام سؤال صعب والعودة له لاحقاً.

### 3. الأقسام الأربعة المتدرجة في كل أسبوع:
1. **المرحلة الأولى: اختيار من متعدد (10 أسئلة مراجعة كحد أدنى):**
   - أسئلة ذكية مبسطة مع فيدباك فوري وشرح بالعامية المصرية وتشجيع بالكونفيتي (Confetti).
2. **المرحلة الثانية: أكواد متقطعة (Fix & Complete Code):**
   - أسطر مقفولة 🔒 لا يمكن للطفل العبث بها، وسطح محدد فقط قابل للتعديل (Editable Line) مع زر تشغيل الكود ومعاينة شاشة الرن (Terminal) والمقارنة مع الناتج المطلوب.
3. **المرحلة الثالثة: مشروع موجه بكومنتات عربي (Guided Project):**
   - كود يحتوي على تعليقات عربية ترشد الطالب خطوة بخطوة داخل الكود.
4. **المرحلة الرابعة: تحدي كتابة الكود كامل (Solo Challenge):**
   - مسألة واقعية يكتب فيها الطفل الكود بالكامل من الصفر.

### 4. لوحة تحكم المدرس الذكية (Teacher Dashboard):
- إحصائيات فورية لعدد الطلاب ونسب الإنجاز.
- جدول بأسماء جميع الطلاب، عدد الأسئلة المحلولة، الأسئلة المتخطاة، ووقت آخر نشاط.
- زر **معاينة الحل 👁️**: يفتح كل سؤال وإجابة الطالب وكوده المكتوب بالتفصيل.
- إمكانية **تصدير درجات الطلاب بصيغة CSV** لفتحها على Excel.
- إمكانية **رفع ملف JSON جديد** للواجب الأسبوعي أو تنزيل قالب الواجب.

## 🚀 كيفية النشر على GitHub Pages في 3 خطوات (Online Deploy)

1. **إنشاء مستودع جديد على GitHub:**
   - ادخل على حسابك في GitHub وأنشئ مستودعاً جديداً (مثلاً: `genie-tasks`).
2. **رفع الملفات:**
   - افتح الطرفية (Terminal) داخل المجلد:
     ```bash
     cd C:\Users\Admin\.gemini\antigravity\scratch\genie-tasks-platform
     git init
     git add .
     git commit -m "Initial commit for Genie Tasks Platform"
     git branch -M main
     git remote add origin https://github.com/USERNAME/genie-tasks.git
     git push -u origin main
     ```
3. **تفعيل GitHub Pages:**
   - ادخل على إعدادات المستودع `Settings` ➔ اضغط على `Pages` من القائمة الجانبية.
   - اختر Branch: `main` واضغط **Save**.
   - خلال دقيقة واحدة سيكون الرابط متاحاً أونلاين لجميع الطلاب وأولياء الأمور!
